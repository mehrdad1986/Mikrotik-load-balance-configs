Triple-WAN Load Balancing and Failover Script

This UI page documents your final RouterOS script for equal PCC distribution across WAN1, WAN2, and WAN3 LTE, with policy-routing fallback and Netwatch connection cleanup.

WAN1

Interface

ether1

IP: 192.168.1.2/24
Gateway: 192.168.1.1

WAN2

Interface

ether2

IP: 192.168.2.2/24
Gateway: 192.168.2.1

WAN3 LTE

Interface

lte1

IP: 10.10.10.2/24
Gateway: 10.10.10.1

LAN

Interface: ether3

Gateway: 192.168.88.1/24

PCC Distribution

Equal distribution across 3 WANs.

1/3 per WAN approximately
!

Before Deployment

Important: This script assumes a clean or prepared configuration. Remove or disable conflicting old dual-WAN rules before importing.

Backup first:

/export file=before-triple-wan
/system backup save name=before-triple-wan

Check interface names:

/interface print
/ip address print
/ip route print detail
/ip firewall mangle print
/ip firewall nat print
/interface lte print detail
If your LAN is on a bridge, replace in-interface=ether3 with your LAN bridge, for example in-interface=bridge-LAN.
1

Interface Roles

/interface set [find where name="ether1"] comment="WAN1-ISP1"
/interface set [find where name="ether2"] comment="WAN2-ISP2"
/interface set [find where name="lte1"]   comment="WAN3-LTE"
/interface set [find where name="ether3"] comment="LAN"
2

Static IP Addresses

/ip address
add address=192.168.1.2/24 interface=ether1 comment="WAN1 address"
add address=192.168.2.2/24 interface=ether2 comment="WAN2 address"
add address=10.10.10.2/24 interface=lte1 comment="WAN3 LTE address"
add address=192.168.88.1/24 interface=ether3 comment="LAN gateway"
3

Local / Private Destination List

/ip firewall address-list
add list=LOCAL address=10.0.0.0/8 comment="RFC1918 private network"
add list=LOCAL address=172.16.0.0/12 comment="RFC1918 private network"
add list=LOCAL address=192.168.0.0/16 comment="RFC1918 private network"
add list=LOCAL address=127.0.0.0/8 comment="Loopback"
add list=LOCAL address=169.254.0.0/16 comment="IPv4 link-local"
4

RouterOS v7 Routing Tables

/routing table
add name=to-WAN1 fib
add name=to-WAN2 fib
add name=to-WAN3 fib
5

Preferred Route in Each PCC Table

/ip route
add dst-address=0.0.0.0/0 gateway=192.168.1.1@main routing-table=to-WAN1 distance=1 check-gateway=ping comment="to-WAN1 preferred via WAN1"
add dst-address=0.0.0.0/0 gateway=192.168.2.1@main routing-table=to-WAN2 distance=1 check-gateway=ping comment="to-WAN2 preferred via WAN2"
add dst-address=0.0.0.0/0 gateway=10.10.10.1@main routing-table=to-WAN3 distance=1 check-gateway=ping comment="to-WAN3 preferred via WAN3"
6

Main Routes and Full Table Fallbacks

Main Table

/ip route
add dst-address=0.0.0.0/0 gateway=192.168.1.1 distance=1 check-gateway=ping comment="MAIN primary WAN1"
add dst-address=0.0.0.0/0 gateway=192.168.2.1 distance=2 check-gateway=ping comment="MAIN backup WAN2"
add dst-address=0.0.0.0/0 gateway=10.10.10.1 distance=3 check-gateway=ping comment="MAIN backup WAN3"

Policy Table Fallbacks

Routing Table Preferred Path Fallback Order
to-WAN1 WAN1 WAN2 → WAN3
to-WAN2 WAN2 WAN1 → WAN3
to-WAN3 WAN3 WAN1 → WAN2 
/ip route
add dst-address=0.0.0.0/0 gateway=192.168.2.1@main routing-table=to-WAN1 distance=2 check-gateway=ping comment="to-WAN1 fallback via WAN2"
add dst-address=0.0.0.0/0 gateway=10.10.10.1@main routing-table=to-WAN1 distance=3 check-gateway=ping comment="to-WAN1 fallback via WAN3"

add dst-address=0.0.0.0/0 gateway=192.168.1.1@main routing-table=to-WAN2 distance=2 check-gateway=ping comment="to-WAN2 fallback via WAN1"
add dst-address=0.0.0.0/0 gateway=10.10.10.1@main routing-table=to-WAN2 distance=3 check-gateway=ping comment="to-WAN2 fallback via WAN3"

add dst-address=0.0.0.0/0 gateway=192.168.1.1@main routing-table=to-WAN3 distance=2 check-gateway=ping comment="to-WAN3 fallback via WAN1"
add dst-address=0.0.0.0/0 gateway=192.168.2.1@main routing-table=to-WAN3 distance=3 check-gateway=ping comment="to-WAN3 fallback via WAN2"
7

Source NAT for Every WAN

/ip firewall nat
add chain=srcnat out-interface=ether1 action=masquerade comment="Masquerade through WAN1"
add chain=srcnat out-interface=ether2 action=masquerade comment="Masquerade through WAN2"
add chain=srcnat out-interface=lte1 action=masquerade comment="Masquerade through WAN3"
8

Exclude Local Traffic from PCC

/ip firewall mangle
add chain=prerouting in-interface=ether3 dst-address-list=LOCAL action=accept comment="Stop PCC for LAN-to-private destinations"
9

Mark New Connections Entering WANs

/ip firewall mangle
add chain=prerouting in-interface=ether1 connection-state=new connection-mark=no-mark action=mark-connection new-connection-mark=WAN1-conn passthrough=yes comment="Mark new inbound WAN1 connection"
add chain=prerouting in-interface=ether2 connection-state=new connection-mark=no-mark action=mark-connection new-connection-mark=WAN2-conn passthrough=yes comment="Mark new inbound WAN2 connection"
add chain=prerouting in-interface=lte1 connection-state=new connection-mark=no-mark action=mark-connection new-connection-mark=WAN3-conn passthrough=yes comment="Mark new inbound WAN3 connection"
10

PCC Classification for LAN

PCC buckets: :3/0 → WAN1 :3/1 → WAN2 :3/2 → WAN3 

/ip firewall mangle
add chain=prerouting in-interface=ether3 dst-address-type=!local connection-state=new connection-mark=no-mark per-connection-classifier=both-addresses-and-ports:3/0 action=mark-connection new-connection-mark=WAN1-conn passthrough=yes comment="PCC bucket 0 -> WAN1"
add chain=prerouting in-interface=ether3 dst-address-type=!local connection-state=new connection-mark=no-mark per-connection-classifier=both-addresses-and-ports:3/1 action=mark-connection new-connection-mark=WAN2-conn passthrough=yes comment="PCC bucket 1 -> WAN2"
add chain=prerouting in-interface=ether3 dst-address-type=!local connection-state=new connection-mark=no-mark per-connection-classifier=both-addresses-and-ports:3/2 action=mark-connection new-connection-mark=WAN3-conn passthrough=yes comment="PCC bucket 2 -> WAN3"
11

Apply LAN Routing Marks

/ip firewall mangle
add chain=prerouting in-interface=ether3 connection-mark=WAN1-conn action=mark-routing new-routing-mark=to-WAN1 passthrough=no comment="Route WAN1-marked LAN connection"
add chain=prerouting in-interface=ether3 connection-mark=WAN2-conn action=mark-routing new-routing-mark=to-WAN2 passthrough=no comment="Route WAN2-marked LAN connection"
add chain=prerouting in-interface=ether3 connection-mark=WAN3-conn action=mark-routing new-routing-mark=to-WAN3 passthrough=no comment="Route WAN3-marked LAN connection"
12

Router-Originated Traffic Exceptions

/ip firewall mangle
add chain=output dst-address-list=LOCAL action=accept comment="Stop output PCC for private destinations"

add chain=output protocol=udp dst-port=53 connection-state=new connection-mark=no-mark action=mark-connection new-connection-mark=WAN1-conn passthrough=yes comment="Pin router UDP DNS to WAN1 table"
add chain=output protocol=tcp dst-port=53 connection-state=new connection-mark=no-mark action=mark-connection new-connection-mark=WAN1-conn passthrough=yes comment="Pin router TCP DNS to WAN1 table"
13

PCC for Other Router-Originated Traffic

/ip firewall mangle
add chain=output connection-state=new connection-mark=no-mark dst-address-type=!local per-connection-classifier=dst-address:3/0 action=mark-connection new-connection-mark=WAN1-conn passthrough=yes comment="Router output PCC bucket 0 -> WAN1"
add chain=output connection-state=new connection-mark=no-mark dst-address-type=!local per-connection-classifier=dst-address:3/1 action=mark-connection new-connection-mark=WAN2-conn passthrough=yes comment="Router output PCC bucket 1 -> WAN2"
add chain=output connection-state=new connection-mark=no-mark dst-address-type=!local per-connection-classifier=dst-address:3/2 action=mark-connection new-connection-mark=WAN3-conn passthrough=yes comment="Router output PCC bucket 2 -> WAN3"
14

Apply Router Output Routing Marks

/ip firewall mangle
add chain=output connection-mark=WAN1-conn action=mark-routing new-routing-mark=to-WAN1 passthrough=no comment="Route router output through WAN1 table"
add chain=output connection-mark=WAN2-conn action=mark-routing new-routing-mark=to-WAN2 passthrough=no comment="Route router output through WAN2 table"
add chain=output connection-mark=WAN3-conn action=mark-routing new-routing-mark=to-WAN3 passthrough=no comment="Route router output through WAN3 table"
15

Multi-WAN Compatibility

/ip settings set rp-filter=loose

/ip firewall filter disable [find where action=fasttrack-connection]

/system script
add name=log-wan-status policy=read,write,test source={:log info "Triple-WAN status check executed"}
16

Netwatch and Connection Cleanup

/tool netwatch
add host=192.168.1.1 interval=5s timeout=1s down-script={/ip firewall connection remove [find where connection-mark="WAN1-conn"]} comment="Monitor WAN1 gateway"
add host=192.168.2.1 interval=5s timeout=1s down-script={/ip firewall connection remove [find where connection-mark="WAN2-conn"]} comment="Monitor WAN2 gateway"
add host=10.10.10.1 interval=5s timeout=1s down-script={/ip firewall connection remove [find where connection-mark="WAN3-conn"]} comment="Monitor WAN3 gateway"

Full RouterOS Script

Copy this block and paste it into MikroTik Terminal, or save it as a .rsc file and import it. 

###############################################################################
# TRIPLE-WAN PCC LOAD BALANCING + FAILOVER
# Target: MikroTik RouterOS 7.23.1 / 7.23.2
#
# WAN1: ether1 = 192.168.1.2/24, gateway 192.168.1.1
# WAN2: ether2 = 192.168.2.2/24, gateway 192.168.2.1
# WAN3: lte1   = 10.10.10.2/24,  gateway 10.10.10.1
# LAN:  ether3 = 192.168.88.1/24
###############################################################################

/interface set [find where name="ether1"] comment="WAN1-ISP1"
/interface set [find where name="ether2"] comment="WAN2-ISP2"
/interface set [find where name="lte1"]   comment="WAN3-LTE"
/interface set [find where name="ether3"] comment="LAN"

/ip address
add address=192.168.1.2/24 interface=ether1 comment="WAN1 address"
add address=192.168.2.2/24 interface=ether2 comment="WAN2 address"
add address=10.10.10.2/24 interface=lte1 comment="WAN3 LTE address"
add address=192.168.88.1/24 interface=ether3 comment="LAN gateway"

/ip firewall address-list
add list=LOCAL address=10.0.0.0/8 comment="RFC1918 private network"
add list=LOCAL address=172.16.0.0/12 comment="RFC1918 private network"
add list=LOCAL address=192.168.0.0/16 comment="RFC1918 private network"
add list=LOCAL address=127.0.0.0/8 comment="Loopback"
add list=LOCAL address=169.254.0.0/16 comment="IPv4 link-local"

/routing table
add name=to-WAN1 fib
add name=to-WAN2 fib
add name=to-WAN3 fib

/ip route
add dst-address=0.0.0.0/0 gateway=192.168.1.1@main routing-table=to-WAN1 distance=1 check-gateway=ping comment="to-WAN1 preferred via WAN1"
add dst-address=0.0.0.0/0 gateway=192.168.2.1@main routing-table=to-WAN2 distance=1 check-gateway=ping comment="to-WAN2 preferred via WAN2"
add dst-address=0.0.0.0/0 gateway=10.10.10.1@main routing-table=to-WAN3 distance=1 check-gateway=ping comment="to-WAN3 preferred via WAN3"

/ip route
add dst-address=0.0.0.0/0 gateway=192.168.1.1 distance=1 check-gateway=ping comment="MAIN primary WAN1"
add dst-address=0.0.0.0/0 gateway=192.168.2.1 distance=2 check-gateway=ping comment="MAIN backup WAN2"
add dst-address=0.0.0.0/0 gateway=10.10.10.1 distance=3 check-gateway=ping comment="MAIN backup WAN3"

/ip route
add dst-address=0.0.0.0/0 gateway=192.168.2.1@main routing-table=to-WAN1 distance=2 check-gateway=ping comment="to-WAN1 fallback via WAN2"
add dst-address=0.0.0.0/0 gateway=10.10.10.1@main routing-table=to-WAN1 distance=3 check-gateway=ping comment="to-WAN1 fallback via WAN3"

add dst-address=0.0.0.0/0 gateway=192.168.1.1@main routing-table=to-WAN2 distance=2 check-gateway=ping comment="to-WAN2 fallback via WAN1"
add dst-address=0.0.0.0/0 gateway=10.10.10.1@main routing-table=to-WAN2 distance=3 check-gateway=ping comment="to-WAN2 fallback via WAN3"

add dst-address=0.0.0.0/0 gateway=192.168.1.1@main routing-table=to-WAN3 distance=2 check-gateway=ping comment="to-WAN3 fallback via WAN1"
add dst-address=0.0.0.0/0 gateway=192.168.2.1@main routing-table=to-WAN3 distance=3 check-gateway=ping comment="to-WAN3 fallback via WAN2"

/ip firewall nat
add chain=srcnat out-interface=ether1 action=masquerade comment="Masquerade through WAN1"
add chain=srcnat out-interface=ether2 action=masquerade comment="Masquerade through WAN2"
add chain=srcnat out-interface=lte1 action=masquerade comment="Masquerade through WAN3"

/ip firewall mangle
add chain=prerouting in-interface=ether3 dst-address-list=LOCAL action=accept comment="Stop PCC for LAN-to-private destinations"

/ip firewall mangle
add chain=prerouting in-interface=ether1 connection-state=new connection-mark=no-mark action=mark-connection new-connection-mark=WAN1-conn passthrough=yes comment="Mark new inbound WAN1 connection"
add chain=prerouting in-interface=ether2 connection-state=new connection-mark=no-mark action=mark-connection new-connection-mark=WAN2-conn passthrough=yes comment="Mark new inbound WAN2 connection"
add chain=prerouting in-interface=lte1 connection-state=new connection-mark=no-mark action=mark-connection new-connection-mark=WAN3-conn passthrough=yes comment="Mark new inbound WAN3 connection"

/ip firewall mangle
add chain=prerouting in-interface=ether3 dst-address-type=!local connection-state=new connection-mark=no-mark per-connection-classifier=both-addresses-and-ports:3/0 action=mark-connection new-connection-mark=WAN1-conn passthrough=yes comment="PCC bucket 0 -> WAN1"

add chain=prerouting in-interface=ether3 connection-mark=WAN2-conn action=mark-routing new-routing-mark=to-WAN2 passthrough=no comment="Route WAN2-marked LAN connection"

/ip firewall mangle
add chain=output connection-state=new connection-mark=no-mark dst-address-type=!local per-connection-classifier=dst-address:3/0 action=mark-connection new-connection-mark=WAN1-conn passthrough=yes comment="Router output PCC bucket 0 -> WAN1"
add chain=output connection-state=new connection-mark=no-mark dst-address-type=!local per-connection-classifier=dst-address:3/1 action=mark-connection new-connection-mark=WAN2-conn passthrough=yes comment="Router output PCC bucket 1 -> WAN2"

After Deployment Checks

Run these commands after importing:

/ip address print
/ip route print detail
/routing table print
/ip firewall mangle print stats
/ip firewall nat print stats
/ip firewall connection print where connection-mark~"WAN"
/tool netwatch print detail
Remember: PCC is per-connection load sharing, not true bonding. A single VPN tunnel or single TCP session will normally use only one WAN.
If your LTE interface gets IP and gateway dynamically, do not blindly use 10.10.10.2/24 and 10.10.10.1. Adjust WAN3 settings to match your real LTE modem/carrier setup.
